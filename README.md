# EccPlotByBin
ECC数据分析工具是一款用于分析闪存芯片错误比特数（ECC Error）数据的统计分析软件。 软件能够读取BIN格式的原始数据文件，进行数据过滤、统计分析，并生成可视化图表和报告。  适用场景：固态硬盘(SSD)、U盘、嵌入式存储设备等NAND Flash芯片的ECC数据质量评估。
