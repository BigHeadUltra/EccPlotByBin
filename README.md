# ECC 数据分析工具

## 一、软件简介

ECC数据分析工具是一款用于分析闪存芯片错误比特数（ECC Error）数据的统计分析软件。
软件能够读取BIN格式的原始数据文件，进行数据过滤、统计分析，并生成可视化图表和报告。

**适用场景：** 固态硬盘(SSD)、U盘、嵌入式存储设备等NAND Flash芯片的ECC数据质量评估。

## 二、主要特性

### 2.1 数据读取与过滤
- 支持 1 字节和 2 字节两种数据格式
- 自动识别文件格式（包含 "1k" 的文件使用 1 字节读取）
- 自动过滤无效数据：FF（255）、FFFF（65535）
- 基于配置阈值的数据分类：
  * 有效数据：<= max_value（默认1000）
  * 超限数据：> max_value

### 2.2 统计分析
- **均值（Mean）**：数据算术平均值
- **标准差（Std）**：数据离散程度
- **中位数（Median）**：数据排序后的中间值
- **MAD**：绝对中位差（Median Absolute Deviation）
  * 计算公式：MAD = median(|Xi - median|) × 系数
  * 默认系数：1.4826（用于拟合正态分布）

**阈值线计算：**
- Median + MAD倍数 × MAD系数 × MAD
- Mean + Std倍数 × 标准差

### 2.3 概率分布拟合
支持三种概率分布拟合，直接基于直方图数据（不展开）：
- **正态分布（Normal）**: 基准模型，衡量数据偏离对称的程度
- **对数正态分布（Lognormal）**: 处理右偏长尾数据，反映误差累积效应
- **Gamma分布**: 比对数正态更灵活，拟合磨损过程中的慢累积失效

**分布平移逻辑：**
- 如果数据从0开始（counts[0]>0），则loc=0
- 否则，找到第一个非零的value，loc = value - 1

### 2.4 EM混合分布拟合
使用期望最大化（EM）算法拟合混合分布：
- **四分布模型**：两对对数正态+Gamma分布
- **初始权重**：均匀分布 [0.25, 0.25, 0.25, 0.25]
- **收敛条件**：权重变化 < 1e-6 或最大迭代100次
- **对比分析**：同时输出双分布模型（Lognormal+Gamma）用于对比

### 2.4 可视化输出
每个 BIN 文件处理后生成三张图表：
1. **sorted_data.png**: 排序后的 ECC 数据散点图，含统计阈值线
2. **count_distribution.png**: 错误比特数频率直方图，含统计阈值
3. **distribution_fit.png**: 频率直方图 + 四种分布拟合曲线 + 威布尔阈值

### 2.5 抽样处理说明
- 排序数据图采用分层抽样（Stratified Sampling）绘制
- 分层抽样原理：
  * 将数据按排序后等分为10层（Strata）
  * 每层抽取相同数量的样本（约5000点/层）
  * 确保尾部数据（极端值）有足够的代表性
- 抽样参数：
  * 触发条件：数据量超过5万点时自动启用
  * 抽样总数：50,000个数据点
  * 分层数量：10层
  * 抽样方式：每层独立随机抽样（固定随机种子保证可重复性）
- 抽样优势：
  * 克服简单随机抽样可能遗漏尾部数据的问题
  * 确保数据分布的各区间都有足够样本
  * 中间密集区域和尾部稀疏区域都能得到充分展示
  * 保持整体分布趋势和统计特性不变
  * 统计阈值线基于完整数据计算，不受抽样影响
  * 显著提高绘图速度和响应效率
  * 减少内存占用和图片文件大小
  * 适用于大数据量场景（百万级以上数据点）
- 计数分布图不涉及抽样，使用完整统计数据绘制

### 2.6 智能边界自适应
直方图右边界根据数据最大值自动调整：
- 数据最大值 ≤ 250 → 右边界 = 250
- 数据最大值 ≤ 500 → 右边界 = 500
- 数据最大值 > 500 → 右边界 = 1000

## 三、输入输出定义

### 3.1 输入文件
- **BIN格式数据文件**（*.bin）
  - 普通BIN文件：每2个字节读取一个数据
  - 包含"1k"关键字的BIN文件：每1个字节读取一个数据
- **配置文件**（config.ini）
  - 首次运行自动创建默认配置
  - 支持手动编辑修改参数

### 3.2 输出目录
- 时间戳命名的结果文件夹（格式：`result_YYYYMMDD_HHMMSS_微秒_文件名`）
- 包含以下文件：
  1. **sorted_data.png**    - 排序数据图（散点图 + 统计阈值线）
  2. **count_distribution.png** - 计数分布直方图
  3. **distribution_fit.png** - 分布拟合图
  4. **scanInfo.txt**       - 扫描信息文本报告

## 四、图表详解

### 4.1 排序数据图（sorted_data.png）
- 上方：统计摘要信息
  * 页数统计
  * 中位数系列（Median、Median+MAD×系数）
  * 均值系列（Mean、Mean+Std×系数）
  * 各类阈值的累计百分比
- 下方：散点图
  * 横轴：排序后的页数索引
  * 纵轴：错误比特数
  * 水平线：中位数、中位数+MAD、均值、均值+标准差

### 4.2 计数分布图（count_distribution.png）
- 上方：统计摘要信息
- 下方：直方图
  * 横轴：错误比特数（0~自适应最大值）
  * 纵轴：页数计数
  * 垂直线：四条统计阈值线

### 4.3 分布拟合图（distribution_fit.png）
- 上方：分布拟合参数摘要
  * 四种分布的拟合参数和得分
  * Location Shift（loc）信息
- 下方：直方图 + 四条拟合曲线
  * 横轴：错误比特数
  * 纵轴：页数计数
  * 曲线：四种分布拟合
  * 垂直线：威布尔分布阈值（p=0.00135）

## 五、配置文件

文件：`config.ini`

参数说明：
- **MAD_MULTIPLIER**：MAD倍数系数（默认3.0）
- **STD_MULTIPLIER**：标准差倍数系数（默认3.0）
- **MAD_SCALE**：MAD缩放系数（默认1.4826）
- **MAX_VALUE**：数据阈值（默认1000）

配置示例：
```ini
[SETTINGS]
MAD_MULTIPLIER = 3.0
STD_MULTIPLIER = 3.0
MAD_SCALE = 1.4826
MAX_VALUE = 1000
```

## 六、使用方法

### 6.1 方式一：批处理启动（推荐）
双击 `ecc_analyzer.bat`

### 6.2 方式二：直接运行 Python 脚本
```bash
python ecc_analyzer.py
```

### 6.3 运行流程
1. 程序自动搜索当前目录下的所有.bin文件
2. 找到文件后自动处理（多个文件依次处理）
3. 为每个BIN文件创建独立的输出目录
4. 处理完成后显示"按Enter键退出"

## 七、注意事项

1. **BIN文件放置位置**
   - 将BIN文件放在py文件同一目录下
   - 支持处理多个BIN文件（按文件名依次处理）

2. **配置文件修改**
   - 首次运行自动创建config.ini
   - 修改配置后需重新运行程序生效
   - 参数值需符合实际数据范围

3. **输出目录**
   - 每次运行创建新的时间戳目录（包含微秒）
   - 目录名称格式：`result_年月日_时分秒_微秒_原文件名`
   - 避免覆盖历史数据

4. **数据要求**
   - 数据为正整数
   - 通常值域范围：0~1000
   - 超出阈值的数据单独统计

5. **错误处理**
   - 未找到BIN文件时显示错误提示并退出
   - 处理过程中出错会显示原因并终止
   - 程序不会死机或卡死
